# Screenshots

The PNG files in this folder were captured from the application running locally
(`streamlit run app.py`). For your demonstration evidence, re-capture them on your
own machine so that your system clock / desktop is visible:

1. `streamlit run app.py`
2. Open each section from the sidebar, enter the sample string, and press
   **Win + Shift + S** (Windows) to capture.
3. Save with the same file names to replace these images.
